# AgriSense Copilot — Project Plan

## 1. Problem
Farmers need accessible support to make better crop and farm management decisions using soil and climate data.

## 2. Our application
AgriSense Copilot will build on the existing Smart Agriculture AI Prediction System. It will help users explore crop recommendations and understand the factors behind the predictions.

## 3. First feature
- Enter soil nutrient values (N, P, K) and climate conditions.
- Generate a crop recommendation using the existing model, if it can be run and validated.
- Explain the main input factors in clear language.
- Display limitations and uncertainty rather than presenting predictions as guaranteed advice.

## 4. What we add
Our contribution will focus on making existing AI predictions easier to understand and use for decision-making.

## 5. Validation
We will test the application with several input scenarios, document the results, and evaluate the model with appropriate metrics when the necessary data and code are available.

## 6. Reproducibility
We will document dependencies, setup instructions, data sources, model limitations, and how to run the application.

## 7. Deliverables
- Working application demo
- Source code and data references
- User guide
- Five-minute demo video
- AI tool and prompt log

## 8. Important limitation
We will verify the existing model and dataset before making claims about prediction accuracy or real-world agricultural benefits.

## 9. Team workflow
Each member documents their changes and handover instructions so the next member can continue the work.
